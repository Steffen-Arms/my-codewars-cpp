## Task
given denominator d how many reduced fraction (a fraction with no divider for numenator and denominator other than 1) are there?


## What I learned
think of what information is included indirectly in variables. Here n already contain the information, which primes it is build from. If we divide this prime form n we automatically remove the indirect information of all multiples of this prime from n.

Also be carefull with containers like vectors if handling with big numbers.
